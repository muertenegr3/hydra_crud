# hydra_Crud

API REST CRUD para el proyecto Hydra. Spring Boot 4.0.4 con Java 17, JPA y PostgreSQL (Supabase).

## Recursos

- `/api/empleados` — CRUD empleados
- `/api/pacientes` — CRUD pacientes
- `/api/pais` — CRUD países
- `/api/roles` — GET/POST roles
- `/api/bpm` — datos BPM

## Ejecución

```bash
./mvnw spring-boot:run
```
